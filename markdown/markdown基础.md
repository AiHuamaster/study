# 一.标题（Headings）
使用 # 表示标题，1-6 个 # 对应 H1-H6。
```python
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

另一种写法（Setext 风格，仅支持一级和二级）：

```
一级标题
========

二级标题
-------
```
一级标题
========

二级标题
-------

# 三.列表
无序列表：使用 -、+ 或 *
```
- 项目一
- 项目二
  - 子项目
    - 孙项目
```
- 项目一
- 项目二
  - 子项目
    - 孙项目

有序列表：使用数字加 .
```
1. 第一项
2. 第二项
   1. 子项
   2. 子项
```
1. 第一项
2. 第二项
   1. 子项
   2. 子项

任务列表（GFM 扩展）：
```
- [x] 已完成任务
- [ ] 未完成任务
- [ ] 待办事项
```

- [x] 已完成任务
- [ ] 未完成任务
- [ ] 待办事项

# 四.链接
行内链接：
```
[链接文字](https://example.com)
[链接文字](https://example.com "鼠标悬停提示")
```
[链接文字](https://example.com)
[链接文字](https://example.com "鼠标悬停提示")

参考式链接：
```
[链接文字][id]

[id]: https://example.com "可选标题"
```
[你好][1]

[1]: https://example.com "可选标题"

自动链接：
```
<https://example.com>
<email@example.com>
```
<https://example.com>
<email@example.com>

锚点链接（跳转到标题）：

- 去标点. ()
- 转小写
```
[跳转到标题](#一标题headings)
```
[跳转到标题](#一标题headings)
