## 1.2命令逻辑

```
echo hello
```

```
sleep 3
```
ctrl+C可发送中断信号终止运行
## 1.3命令的基本结构
```
命令名称 [命令参数]...
```
注意:命令名称区分大小写
## 1.4典型的命令参数语法

|类型|作用|语法结构|示例|
|---|---|---|---|
|不带值的短参|一般作为开关使用|*-[参数名]*|-a|
|带值的短参数|用来传递具体的参数值|*-[参数名][参数值]*|-n 10|
|不带值的长参数|一般作为开关使用|*--[参数名]*|-all|
|带值的长参数|用来传递具体的参数值|*--[参数名]=[参数值]*|--size=100|
|位置参数|用于传递具体的操作对象|*[操作对象]...*|sample.txt|

# 2.linux目录结构

| |linux|windows|
|---|---|---|
|目录分隔符|正斜杠/|反斜杠\
|根目录|只有一个跟目录|每个盘都有根目录|
|大小写敏感|区分大小写|默认不区分大小写|
- 绝对路径：以更根目录开头
- 相对路径
  - `..`代表当前目录的上一层
  - `.`代表当前目录
- `~`指定家目录

## 2.1目录命令
1. `cd` 命令：切换目录 change directory
   1. `cd -`返回上个历史记录
2. `ls` 命令：打印目录 list
   1. `-a`：打印隐藏内容（即 . 开头的对象）
   2. `-l`：以详细列表形式打印
   3. `-F`：在文件名后显示类别指示符
   4. `-h`：以更直观的方式显示文件大小
- 补充知识：Linux 中以 . 开头的文件或目录叫隐藏文件或目录，如 .cache、.config、.gitignore 等。
- `ll`=`ls -alf`
3. `pwd` 命令：打印当前工作目录 print working directory
4. `cat` 查看文件 concatenate
5. `mkdir` 命令：新建目录 make directory
   1. `-p`：父目录不存在时一并创建，可用于一次性新建多级目录
6. `touch` 命令：新建文件

## 2.2 查找命令
`find`
```
find [起始目录][查找条件]
```
- `-name 名称`:按照名称查找，区分大小写
- `-iname 名称`：按照名称查找，不区分大小写
- `-type f`：只查找普通文件
- `-type d`：只查找目录
- `-maxdepth n` ：最多向下查找 n 层目录
```
# 在当前目录及其子目录中查找 config.json
find . -name "config.json"
# 在家目录及其子目录中查找所有 .txt 文件
find ~ -name "*.txt"
# 不区分大小写查找所有名称以 readme 开头的对象
find . -iname "readme*"
# 在 /data 中只查找名为 checkpoints 的目录
find /data -type d -name "checkpoints"
# 在 /data 中只查找 .pt 文件
find /data -type f -name "*.pt"
# 只查找当前目录及其下一层，不再继续深入
find . -maxdepth 1 -name "*.txt"
```
## 2.3复制·移动·重命名
`cp`（意味 copy）
- 位置参数 1：原对象路径
- 位置参数 2：目标路径  
- `-r`：是否递归复制（复制目录时使用）
<br>
<br>
- 文件 → 已存在目录：把文件复制到目标目录里面
- 目录 → 已存在目录：把目录复制到目标目录里面
- 文件 → 已存在文件：用文件内容覆盖目标文件（不可恢复！！！）
- 目录 → 已存在文件：报错，无效操作
<br>
<br>
`mv` move
- 位置参数 1：源对象路径
- 位置参数 2：目标路径
<br>
<br>
- 文件 → 已存在目录：把文件放到目标目录里面
- 目录 → 已存在目录：把目录放到目标目录里面
- 文件 → 已存在文件：用文件覆盖目标文件（不可恢复！！！）
- 目录 → 已存在文件：报错，无效操作

## 2.4 删除对象
`rm`删除文件 remove
`rmdir`删除空目录 remove directory
- 位置参数：想删除的文件或目录路径，传多个则同时删除
- `-i`：每次删除前询问用户
- `-I`：在较危险情况下询问用户（递归删除目录，或一次删除超过三个操作对象时，在执行前统一询问一次）
- `-f`：强制删除，不询问用户，操作对象不存在时不报错
- `-d`：删除空目录
- `-r`：递归删除目录
